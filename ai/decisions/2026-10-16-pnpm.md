# pnpm is the package manager

Date: 2026-10-16 · Status: accepted

## Context

The project was scaffolded with pnpm, and the workspace standard does not fix a package manager.
The author kept pnpm.

## Decision

- `pnpm` for every install and script; `pnpm-lock.yaml` is the only lockfile.
- No `packageManager` or `engines` field in `package.json` (the workspace standard leaves them out)
  unless a later decision needs one.
- CI installs with `pnpm install --frozen-lockfile`.

## Consequences

- Commands in the docs, prompts and Linear issues are `pnpm …`.
- A `package-lock.json` or `yarn.lock` that appears is a mistake: remove it.

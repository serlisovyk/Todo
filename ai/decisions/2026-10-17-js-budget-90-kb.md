# Bundle size budgets: JavaScript 90 kB, CSS 8 kB (gzip)

Date: 2026-10-17 · Status: accepted

## Context

`bundle-size-budgets` set the JavaScript budget at 80 kB when the bundle was React and React DOM
alone, 67.9 kB gzip. With the task list, the form, the theme, and the editing and toast work, the app
is at about 79 kB, and about seven feature tasks remain: filters and search, export and import, and
more. At 80 kB the next feature crosses the budget.

## Decision

- The JavaScript budget is 90 kB gzip in `.size-limit.json`.
- Everything else of `bundle-size-budgets` stays in force: `size-limit` with `@size-limit/file`; the
  CSS budget of 8 kB gzip; the font's own budget in raw bytes; `pnpm size` runs after `pnpm build`,
  locally and in CI.

## Consequences

- About 10 kB of room for the remaining features. A change that still crosses 90 kB is questioned
  first (a lighter way, a smaller import); raising the budget again is a new record with the reason.
- Rejected: holding 80 kB by trimming, because React and React DOM are most of the bundle and the
  app code has little left to trim; no budget at all; brotli sizes (the reports read gzip).

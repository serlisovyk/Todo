## The demo GIF

- Source: `pnpm build` and `pnpm preview --port 5196 --strictPort`, so the GIF shows the shipped bundle. Headless Chrome
  runs on port 9236 with a profile of its own in a temporary folder, driven over the DevTools protocol by Node's
  global `WebSocket`; the scripts live in `scratchpad\my163\`, not in the repo.
- Start state: the page seeded with eight sample tasks (English titles, no personal data, five categories, mixed
  priorities, one checked) through `todo:data`, the light theme, a window 800 px wide and 800 px high, which shows
  four task rows.
- Scenario, about 30 seconds: the list, then a task typed into the form, its category and priority chosen from the open
  pills, and added; the page scrolled down to the footer and a task checked, so the row sinking below the open ones and
  the tasks-left counter show, then scrolled back; the search field focused with `/`, a query typed, the highlight
  shown, the field cleared; the Category pill opened and a category chosen, the Sort pill opened and Priority chosen,
  Reset; the dark theme (the circle reveal), then back to light. The page gets a drawn pointer and click ring
  injected at record time so a viewer can follow the mouse; nothing of it reaches the app.
- Frames: a loop of timed `Page.captureScreenshot` calls (about 24 frames a second, each with its time), at the
  native 800 px so the text and the one-pixel borders stay crisp. A one-off ffmpeg from the `ffmpeg-static` package,
  installed with npm into the scratchpad, cuts the frames to 20 a second, builds one palette from them
  (`palettegen` with `stats_mode=diff`) and writes a GIF that loops forever. Identical frames cost almost nothing,
  so the file lands near 1 MB, lighter than the 2–3 MB the author allowed.
- Checked: size, dimensions, frame count, loop count, and stills pulled from the file and looked at.

## Social preview

The same scene as `public/og-image.png`, rendered at 1280×640 into `scratchpad\my163\social-preview.png` only, by the
recipe of `ai/skills/og-image.md` (two iframes with a theme each, headless Chrome). The same page rendered at 1200×630
is first compared with `public/og-image.png`, and the render must match it pixel for pixel, so the 1280×640 file shows
the same scene. The skill's checks run at that size: the exact dimensions, the page colour on both sides of the
diagonal, and the logo's and the name's bounding boxes in their own triangles.

## Deliberate choices

- **The GIF is a file in the repo, the social preview is not.** GitHub resolves the README's relative image path from
  the repository; the social preview is uploaded in the repository settings and has no path.
- **No Architecture Notes section.** The layers are in the intro and the tree; the rules and their reasons are
  `ai/rules/architecture.md` and `ai/decisions/`, and a README copy would be a second home for the same fact.
- **The scripts omit `lint:fix` and `prepare`.** One is a convenience for `lint`, the other runs by itself on
  `pnpm install`; the section lists what a reader runs.
- **The size budgets are a link, not numbers.** They are in `.size-limit.json`, so one place changes them.

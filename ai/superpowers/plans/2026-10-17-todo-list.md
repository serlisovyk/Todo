## Code

Layers and file names follow `structure-and-naming` and `context-folders`; each new folder gets its
`index.js`.

- `package.json`, `pnpm-lock.yaml` — `lucide-react` through `pnpm add lucide-react`, in its own
  commit so the rebase after MY-151 resolves one small conflict (`scope.md` already lists it).
- `src/utils/todos.utils.js` (and the barrel) — `sortTodos(todos)`: active before completed, then
  newest first by `createdAt`, through a private `compareTodos(first, second)` and `toSorted`, so
  the input stays as it is.
- `src/components/todo-item/` — `TodoItem({ todo })`: one `<li>` with a `<label>` (the checkbox,
  a `Check` icon and the title) and a `<div>` of meta (the category, the priority). It calls
  `useTodos()` for `toggleTodo`, finds the category and the priority labels in `CATEGORIES` and
  `PRIORITIES`, and puts `data-category` and `data-priority` on the category and the priority
  elements. `todo-item.css` styles the row.
- `src/styles/colors.css`, `src/styles/style.css` — `colors.css` maps each `data-category` value
  to `--category-color` and each `data-priority` value to `--priority-color`, from the colour
  tokens; `style.css` imports it between `tokens.css` and `base.css`.
- `src/components/todo-list/` — `TodoList()`: reads `todos` and `isLoading` from `useTodos()` and
  renders the loading text, the empty text, or the `<ul>` of `TodoItem` (imported from
  `@/components/todo-item`, keyed by `todo.id`) over `sortTodos(todos)`. `todo-list.css` styles
  the card and the two texts.
- `src/components/index.js` — a line for each new folder. `src/components/app/app.jsx` — the
  `Todo` placeholder in `<main>` becomes `<TodoList />`, imported from `@/components/todo-list`.

### Deliberate choices

- **`TodoItem` takes only `todo` and calls `useTodos()` itself.** Edit and delete (MY-153) add more
  actions to the row; one hook call replaces a growing list of callbacks through one level.
- **The label wraps the checkbox and the title and nothing else, so the name is the title.** The
  meta sits outside it and is tied to the checkbox with `aria-describedby` (`useId`), so a screen
  reader user who tabs through the checkboxes still hears the category and the priority. The
  accessibility tree of the built row is checked for this (Verification).
- **A custom checkbox, not the native look:** `appearance: none` with the `--color-border-control`
  outline, the accent fill when checked and a lucide `Check` over it. The check is an icon, not a
  background image or a border trick, so it needs no raw colour and survives forced-colors mode
  (its colour is the text colour there). The icon is shown through `:checked +`, and the title is
  struck through through `:checked ~`, so the row needs no `is-*` class.
- **Two lines, always:** the title above, the meta below, indented by the checkbox column
  (`--todo-item-checkbox-size` plus the gap, both from `--space-*`). One layout from 320px to
  desktop instead of a media query that moves the meta; a long title cannot squeeze the meta.
- **The whole label is the target**, `min-height: var(--touch-target)`, with the checkbox aligned to
  the first line of a long title. The checkbox itself stays at `--space-6`.
- **No live region on the loading and empty texts.** `react.md` allows one polite region for what
  a user must hear; deleting and Undo are the toast's announcements, and the list appears too
  quickly with localStorage to be worth one.
- **`sortTodos` compares `Date.parse(createdAt)`**: the stored timestamps are canonical ISO
  strings, so the numbers are exact; the sort is stable, so a tie keeps the stored order. It is
  computed on every render, with no state and no memo (`react.md`).
- **The priority shows a label beside the flag**, as the category shows its name: a colour alone
  would not carry the meaning, and the screen reader hears the same words as the screen. The flag
  is decorative (`aria-hidden`), an outline in the priority colour; the label uses the muted meta
  colour.
- **The `Todo` text in `<main>` goes.** It was the shell's placeholder; the header with the real
  `<h1>` comes with the form (MY-151).
